# Security policy

Best Before is security software that runs with elevated access on other people's servers. We take reports about its own security seriously.

## Reporting a vulnerability

**Please do not open a public issue.**

Report vulnerabilities privately through GitHub's private vulnerability reporting: go to the repository's **Security** tab and choose **Report a vulnerability**.

Please include:

- the affected component (`bestbefore-agent` or `bestbefore`) and version;
- a description of the issue and its impact;
- steps to reproduce, or a proof of concept.

We aim to acknowledge reports within a few working days and will keep you informed while we work on a fix. We are happy to credit you in the release notes unless you would rather stay anonymous.

## Supported versions

The project has not had a stable release yet. Until it does, only the latest commit on `main` is supported.
